Pantech Dynamics

An identity for
Africa’s data centre

Visit pantechdynamics.com
Introduction

Pantech Dynamics runs cloud servers and colocation from Abuja, so African data stays in Africa. We built its identity: the mark, the system, the brand book and the launch graphics.

Industry
Cloud infrastructure / Data centre
Location
Abuja, Nigeria
Scope
Brand strategy, Logo, Identity system, Brand book, Graphics
Year

Live
pantechdynamics.com ↗
01The challenge

One name for the whole field.

Pantech had to read as all of technology, not as a software, security or AI company. The name already said it, so the identity had to carry it.

02Logo exploration

Ten directions, one choice.

Ten different arguments for how the idea takes form, each judged in one colour on its silhouette. Orbit was chosen: the only curved direction, with warmth for buyers who aren’t technical.

  • 01Modular
  • 02Dynamic P
  • 03Forward Vector
  • 04Delta
  • 05Aperture
  • 06Shear
  • 07Dimensional
  • 08PD Monogram
  • 09Convergence
  • 10Orbit
03Brand identity

The circle is never closed.

A solid core with three arcs that open the same way. The outer arcs are the least complete, so the mark reads as still growing.

  • Black#000000
  • Ink#0A0C10
  • Graphite#1B1E24
  • Steel#6E7681
  • Ash#CDCDC9
  • Mist#F5F4F1
  • White#FFFFFF
  • Orbit Blue#1E56FF
  • Orbit Blue Light#5B86FF
04Graphics

Say it plainly. Prove it with numbers.

Twelve launch posts, one argument and one number each, all from the same system.

05Pattern

One rule, left running.

Repeat the mark’s rule and it becomes the field behind everything: sweeps, chrome and light.

06Brand in the world

Built, not just printed.

Posters, out-of-home, the welcome kit and the reception wall, each from the same three colours.

07The brand book

Thirty-two pages, one system.

Foundation, logo, colour and type, pattern, applications and governance, so anyone at Pantech can use the brand the same way.

From a name to a brand that spans the field.

We turned Pantech’s ambition into a mark, a system and a book the team can run with. If your business needs a brand that holds together everywhere, start here.
